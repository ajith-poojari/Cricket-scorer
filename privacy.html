Privacy Policy

Last updated: 15 September 2026

This is a free, community scoring tool for cricket matches. It is built to work with the least amount of personal data possible — there are no accounts, no sign-up forms, and nothing to identify you by name or email to use it.

What is stored

  • Whatever you type into the setup screen — team names, player names, venue, and match details — since these are needed to run the scoreboard.
  • Ball-by-ball scoring data as the match is logged.
  • An anonymous device identifier, created automatically by Firebase Authentication when you connect. This identifier is a random string tied to your browser session, not to your real identity.
  • A one-way cryptographic hash of the scorer password you set for a match, used only to confirm you're re-entering the same password. The original password itself is never stored or transmitted anywhere.

What is not collected

  • No cookies used for tracking or advertising.
  • No analytics or third-party trackers.
  • No advertising of any kind.
  • No email address, phone number, or payment information is ever requested.

Where data lives

Match data is stored in Google Firebase Realtime Database, a third-party service operated by Google. Firebase's own privacy terms govern how Google handles the underlying infrastructure. Anyone with a match's code can read that match's live data — that's what makes the "viewer" feature work — but only the device that created a match, using its own password, can change it.

How long data is kept

Match data persists in the database until it is manually removed. There is no automatic deletion after a match ends.

Your choices

This tool's code is open — anyone can host their own copy connected to their own Firebase project, which keeps that copy's match data entirely separate from any other deployment.
